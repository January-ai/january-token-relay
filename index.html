This relay is for development and testing — before launch, move the endpoint into your backend. See the README.

1 · Mint a client token

curl -X POST 'https://<your-project>.vercel.app/api/january/client-token' \
  -H 'Authorization: Bearer <your RELAY_TOKEN>' \
  -H 'x-end-user-id: demo-user-1'

Replace <your RELAY_TOKEN> with the relay token you set in .env or at deploy. The user id can be anything — the token is minted for that user.

2 · Use it — search for greek yogurt

curl 'https://partners.january.ai/v1.2/foods?query=greek+yogurt&limit=3' \
  -H 'Authorization: Bearer <ct-token from step 1>'

Paste the ct-… value from step 1. Tokens expire after ~30 minutes — just mint another.
